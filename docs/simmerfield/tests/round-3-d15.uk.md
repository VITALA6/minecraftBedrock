# Тестовий сценарій, раунд 3: примарні інгредієнти, плакати рецептів, вибір у казані (D15)

Переклад [`round-3-d15.md`](round-3-d15.md). Якщо версії розійдуться, правильна англійська.
Повідомлення в лапках — з гри, тож англійською.

D15 замінило книгу рецептів примарними інгредієнтами над казаном і плакатами рецептів на стіні;
екран казана відкривається лише тоді, коли є справжній вибір. Цей раунд також містить перевірки з
раунду 2, які ще актуальні (колір рідини, торт B15, Content Log). Кроки про книгу з
[`round-2-book.uk.md`](round-2-book.uk.md) більше не потрібні.

Одна сесія, згори донизу. Звітуйте з цими номерами: `ok` або що побачили натомість (для примар і
плакатів допомагає скриншот). Відкриті питання: [`../blockers.md`](../blockers.md) (тут
перевіряються B15, B16, B22–B24).

## Підготовка

1. Content Log File увімкнено. Відкрийте тестовий світ (або новий: Creative, cheats увімкнено, без
   експериментів, лише Simmerfield). Якщо світ був відкритий — **вийдіть і зайдіть знову**:
   блоки, частинки й текстури змінилися.
   → без діалогу з помилкою паку. Політайте 1–2 хвилини.
2. `/wm_kitchen:debug validate` → `Data check: 0 problem(s)`.
3. `/gamemode s`, `/wm_kitchen:debug reset`, `/clear`, потім `/give @s wm_kitchen:tomato`.
   → приходить **один Recipe Poster** і `★ You got a Recipe Poster!`. `/give @s wm_kitchen:onion` другого
   плаката не дає. (Книги рецептів більше немає.)
4. `/wm_kitchen:debug kit`.

## Примарні інгредієнти (D15, B22–B23)

Казан на запаленому вогнищі.

5. Порожній казан.
   → нічого не літає. Порожня рука + використання → `Add ingredients`, без форми.
6. Додайте 1 цибулину.
   → над казаном гойдаються напівпрозорі іконки (риба, що кожні 2 с міняється тріска/лосось,
   картопля, миска). Обійдіть казан: ряд повертається до вас. Порожня рука + використання →
   `Add Cod / Salmon` в action bar, без форми.
7. Додайте хліб.
   → примари стають цибулею + мискою. Додайте цибулину → маленький білий «поп» на місці її
   примари; лишається тільки миска.
8. Додайте миску.
   → дзвін, потім іконка Onion Soup із золотими іскрами. Порожня рука + використання → одразу
   вариться без форми; поки кришка закрита, нічого не літає.
9. Коли готово.
   → іконка супу літає майже непрозора. Використання → ви отримуєте суп, іконка зникає.
10. 2 помідори, 2 цибулини, хліб і миска.
    → літають дві іконки страв. Використання → форма «Cooking Pot» з двома кнопками `Cook …`
    **з іконками**, без кнопки Close, без прокрутки. Виберіть одну → вариться. Загасіть вогонь і
    повторіть → шипіння + `♨ Needs fire below`, без форми.
11. Три казани з інгредієнтами поруч.
    → примари лише над найближчими двома. Відійдіть далі ніж на 6 блоків → жодних.
12. Читабельність: подивіться на примари на траві, на дошках і вночі.
    → кожну іконку видно; запишіть ті, що погано читаються.
13. (За бажанням, другий гравець) кожен бачить свій ряд, повернутий до себе; обидва бачать «поп».
14. `/wm_kitchen:debug pot`, дивлячись на казан → є рядок `ghosts …`.

## Плакати рецептів (D15, B24)

15. Дивлячись прямо на стіну шириною 2 блоки, поставте плакат.
    → **два блоки**, рецепт Tomato Soup читається зліва направо, лицем назовні. Повторіть на
    північній, південній, східній і західній стінах.
16. Спробуйте під гострим кутом уздовж стіни, там, де вільний лише один блок стіни, і на
    підлогу або стелю.
    → `Look straight at the wall` / `Needs a 2-block wall` (плакат лишається у вас), на підлогу
    чи стелю — нічого.
17. Використайте плакат.
    → `Tomato Soup · ❤ Regeneration 8 s` в action bar.
18. Присід + використання кілька разів (ви знайшли помідор і цибулю).
    → перебирає лише відкриті страви, у порядку рецептів, потім по колу. Блок у руці під час
    присіду не ставиться.
19. `/wm_kitchen:debug reset`, потім присід + використання.
    → `Break grass to find seeds`, без змін. Плакат, поставлений зараз, — порожній «трава →
    насіння → ?».
20. `/gamemode c`, присід + використання.
    → усі 13 страв, потім по колу. Назад `/gamemode s`.
21. Зламайте будь-яку половину, потім (новий плакат) зламайте стіну за однією половиною, потім
    спробуйте TNT і поршень.
    → зникають обидві половини й випадає **рівно один** плакат щоразу; нічого не висить у
    повітрі. У creative нічого не випадає.
22. Верстак: папір + кожна з 5 культур.
    → по 1 плакату.
23. З відстані 4–5 блоків.
    → іконки й `8 s` читаються (ПК; телефон, якщо є).

## Перенесено з раунду 2

24. Колір рідини (вогнище горить): 1 цибулина → **золотиста**; додайте 2 помідори → **червона**;
    вийміть усе → зникає. З `/wm_kitchen:debug fast`: джем **рожевий**, chowder **кремовий**, chili stew
    **темно-червоний**, vegetable stew **коричневий**, onion/chicken soup **золотистий**, лише
    миска + цукор — **прозора вода**. Приберіть вогонь → обідок холоне, колір лишається (B16).
25. Торт (B15): на стіну чи стелю → не ставиться. На землі, з'їжте шматок, зламайте землю → торт
    вискакує, **нічого не випадає**. Поршень під ним → вискакує, нічого не випадає.

## Завершення

26. Вийдіть і прочитайте найновіший файл Content Log:
    `f=$(ls -t ~/.var/app/io.mrarm.mcpelauncher/data/mcpelauncher/games/com.mojang/logs/ContentLog*.txt | head -1); grep -v '\[verbose\]' "$f" | grep -v '^$' | grep -v 'No sound found' | tail -100`
    → `data check: 0 problem(s)`; немає `can't read food`; немає Molang-рядків
    `unknown variable`; немає помилок частинок, текстур, permutation чи multi-block
    (`wm_kitchen:recipe_poster`, `wm_kitchen:ghost_icon`). Вставте у звіт кожен рядок з `wm_kitchen`.
